Some helper scripts for simh vax simulator and Open VMS 7.1
using root account to run the scripts in a Debian 13 server vm.
The vm can be a minimal install and only needs to have 1Gb RAM and about 3Gb free disk space for this simulator.

See https://www.openvmshobby.com/vax-vms/ and https://www.vaxhaven.com/CD_Image_Archive
